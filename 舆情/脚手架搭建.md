# 舆情与事件模块 · 脚手架与实施说明

供 `#/news`、Yuqing Worker、D1 与定时抓取对齐；**未接线能力一律保留页面 PLANNED 占位**，勿随意删除。

---

## 一、信息架构（事实池 + 按需 LLM）

- **服务端事实池**：免费/低成本聚合（FNG、BTC、RSS/Finnhub 新闻与经济日历条目等）经 Cron 写入 **D1** `yuqing_items` / `yuqing_snapshots`，保留约 **7 天**。
- **前台首屏**：优先 **`GET /api/yuqing/latest`**（同源聚合 `sources` + 最近 D1 条目）；失败时读本地 **`localStorage` `yuqingDaily_latestWorkbench`** 兜底。
- **按需解读**：**`POST /api/yuqing/report`** 默认以 D1 事实 **grounding** 提示词；仅在事实偏少、`allowSearch` / `forceSearch`、或环境 **`YUQING_LLM_ALWAYS_SEARCH=1`** 等条件下由 Worker 侧启用 **Google 搜索补洞**。
- **页面布局**：**市场脉冲**（FNG + 跨资产摘要）+ **统一事件流** + **日历窄栏**（Macro/Crypto 线索）+ **分析卡片**；不再采用「上采集、下 LLM」的硬分区文案。

## 二、后端 · `yuqing` Worker

| 项 | 说明 |
|----|------|
| 代码 | `cloudflare/yuqing-worker.js`；事实抓取与 D1 读写辅助：`cloudflare/yuqing-facts.js` |
| 配置 | `cloudflare/wrangler.yuqing.toml`（**独立**于 btc Worker）；需配置 **D1 `database_id`**（`wrangler d1 create yuqing` 后填入） |
| Cron | `0 * * * *`（整点，约 60 分钟一次）→ `scheduled` → `ingestFactPool` |
| 手工 ingest | `POST /api/yuqing/ingest`，请求头 **`X-Yuqing-Cron-Secret`** 与 Worker 密钥 **`CRON_SECRET`** 一致 |

### 主要 HTTP 路由

- `GET /api/yuqing/health` — 健康与密钥摘要（含 `secrets.d1Ready`）
- `GET /api/yuqing/sources` — 仅聚合市场源（无 D1 条目列表）
- **`GET /api/yuqing/latest`** — 推荐前端首屏：聚合源 + 最近 D1 条目 + `capturedAt` / `d1Ready`
- `GET /api/yuqing/items` — 按 `category`、`limit` 分页列表
- `GET /api/yuqing/history?days=7` — 轻量统计
- **`POST /api/yuqing/report`** — 按需编排；响应含 **`grounding`**（`factCount`、`usedSearch` 等）
- `POST /api/yuqing/llm/test` — LLM 连通性

### D1 迁移

- 初始化：`cloudflare/migrations/yuqing/0001_init.sql`（`yuqing_snapshots`、`yuqing_items`、`yuqing_report_runs`）
- 远程执行示例：`npx wrangler d1 execute <DB_NAME> --remote --file=cloudflare/migrations/yuqing/0001_init.sql`（以实际 toml 中库名为准）

### 典型 Secrets

- **`FINNHUB_API_KEY`** — 市场/宏观新闻等
- **`CRON_SECRET`** — 保护 `ingest` 手工触发
- **Gemini**：`GEMINI_API_KEY` / `GOOGLE_API_KEY`，`YUQING_LLM_PROVIDER` 等
- **`YUQING_LLM_ALWAYS_SEARCH`** — 设为 `1` 时倾向始终开搜索（慎用配额）

## 三、前端 · `#/news`

| 项 | 路径 |
|----|------|
| 页面 | `js/pages/news.js` |
| API 基址 | `js/config.js` → `getYuqingApiBase()` |
| 请求封装 | `js/data-engine.js`：`fetchYuqingLatest` / `fetchYuqingItems` / `fetchYuqingHistory` / `generateYuqingReport` 等 |
| 样式 | `styles.css`：`news-workbench*`、`news-pulse-grid`、`news-item--fact`、`news-grounding-hint`、`yuqing-*` |

交互要点：`initNews` 先用本地 **latestWorkbench** Hydrate →  Hydrate **日报**（`skipMarketPulse`，避免覆盖脉冲区）→ 自动 **`refreshYuqingLatestFromWorker`**。
