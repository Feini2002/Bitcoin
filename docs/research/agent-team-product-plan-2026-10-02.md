## 1. 已确认目标与使用流程

- 首席决策台为主入口，先读判断、变化、反证、缺口，再展开岗位依据。
- 行情、盘口、衍生品、宏观与事件独立研究；首席综合，不按人数投票。
- 首要输出是理解市场变化、解释可靠性及下一步核查；不承诺交易或预测成绩。
- 固定节奏由用户在设置选择；第一版仅开发版页面打开期间运行，初始关闭。
- 全部模型步骤使用官方 Codex CLI 的 ChatGPT 登录额度，运行方式只在设置和折叠诊断解释。

流程：最后接受的首席及原时点 → 手动更新或已开启计划 → 专员独立发现/补查/交付 → 首席逐岗处置与必要追问 → 审核 → 接受精确版本 → 原岗位/原件/条件 → 下一轮冻结基线比较。失败不覆盖最后接受结果。没有账户信息就不编造仓位。

## 3. 架构分层和真实关联

| 层 | 责任 |
| --- | --- |
| 数据与原件 | Worker/D1 与事件只读口；来源、时钟、单位、覆盖、原响应 |
| 取证 | tools.mjs；岗位白名单、有界 GET、确定性计算、失败回执 |
| 独立岗位 | contract/prompts/service；本领域输入、自主请求、反证及轮前观点 |
| 首席与审核 | 有效岗位、精确基线/引用、逐岗处置、一次追问、有限修订 |
| 运行控制 | store/schedule/provider/process-tree；排他所有权、预算、租约、取消、清理 |
| 阅读 | 首席、指定版本 reader、任务结果、证据、记录、历史与设置 |

只有一个 Node 执行器。模型返回结构化工具请求，Node 验参执行；任意 shell、网络与插件关闭。独立会话不等于独立来源，同所序列与原文/转载不能重复计票。

五个岗位均可按需读取已有Binance永续5m/15m/1h/4h/1d/3d/1w行情作为价格背景，默认种子和领域职责不变。每次仍最多200行，指定窗口不能借换周期扩大；完整性、不同闭合截止和产品口径按实际回执说明。自己的工具范围和本轮资料缺口不能泛推为全系统没有对应能力；宏观区间筛选只作用于参考期，不证明该窗没有公布或宏观影响。

历史观点与历史工作材料分开：宏观岗接受稿即使没在正文引用某条FRED，上一稿实际取得、归属该稿且有效的原回执仍可带入每序列两个最新参考期端点。保留原ID、索引、值、单位、时钟和基线归属，当前投影保留共同参考期的实际行；仅供复核，不当新发布、不认证旧观点。未匹配部分保持未知。首席保留本轮完整岗位、旧首席、历史岗位摘要/完整反证和直接引用旧数值，明确省略旧主张原文及无关祖先，不递归扩展旧材料；当前有界引用行、端点、内部极值及最早样本仍保留完整字段，完整统计和完整指定K线窗口保留。新增候选引用补并集，完整原件按原ID展开。未引用字段可能支撑反证，不能只按主张引用删掉当前材料。

关联链：入口 → 明确选择 → 任务/材料身份 → 实际取证 → 封存 → 独立岗位 → 首席/审核 → 接受版本 → 阅读/导出/恢复。图表、准备包和团队回执不是同一原子输入，不能读 DOM 猜范围或借页面卡片宣称 Agent 能力。

## 5. 知识、记忆与时间归属

方法检索最多 3 条/8192 字节，登记来源、版本、核验时间、适用域、冲突与陈旧。方法资料没有指令权，也不是市场证据；marketEvidence=false，不能作为行情主张引用。已按实际发送材料选方法，真实宏观输入包含 FRED 频率、单位及 vintage 方法，报告保留周三存量、周平均和日频操作额的差别。方法传递及正确引用不单独证明模型理解或外部因果。

每岗冻结最后接受报告及被引原回执。首席冻结自己和各岗基线，当轮提交不能成为“上一轮”。维持/修订/撤回绑定精确 ID，区分新增样本、资料更正、方法变化与旧判断错误。current 与专题接受指针隔离。

条件账本每份报告最多12条。自动条件仅核查合格的闭合Binance K线及绑定真实字段/数值/单位的门槛：已取得栏实际命中可记触发；未触发或到期的负结论需要完整有效覆盖，缺口保持未知。服务记录实际登记点，新条件在完整原生栏前登记，旧生成时间不补认证。自然语言观察保持人工待核查；修订新增关联，不覆写原条件。

输入截止、参考期、公开/接收、完成与登记时间不同。哈希一致不证明真实或严格 PIT。无变化守卫检查材料、质量、新鲜度、方法/Prompt 与条件；曾补查的岗不能只凭默认种子不变跳过。首席复用还需五岗版本与原首席轮一致。

## 6. 执行、预算和失败恢复

1. 所有权/页面/配置核对，耐久请求，冻结基线。
2. 岗位批次并发2，每岗常规研究最多3次调用；前两次最多各2个工具请求，最后只交付。全队另可向一岗澄清1次，只交付、不重开工具循环，仍计入整轮预算和截止。
3. 一岗失败保留原回执与旧观点，其他岗继续；全部无有效观点或必要任务材料缺失则不足。
4. 首席逐岗采纳/未采纳/待核实/缺失，全队最多一次澄清。
5. schema、引用、数字、单位、基线、条件校验；语义审核解释/反证/时钟/来源，最多一次修订。审核 accept 不认证外部真相。
6. 接受不可变版本；精确清理后释放，不确定或存储失败停止新步骤。

当前执行边界：模型输入384KiB，超过224KiB先用既有无损编码共享重复字段，不丢当前报告、关键反证及引用身份。真实五岗比较材料无损包约287KB，原256KiB预检失败已保留；384KiB通过对应首席、审核及修订容量回放，仍须真实输出验收，不等于模型上下文或性能保证。单轮20次/55分钟；岗位、首席、审核均最多12分钟且受整轮余时约束；独立清理15秒。仅具体截止失败且确认退出时可在保留首席/审核预算后进行已有的有界最终稿补交，不自动重试其他故障。跨日按真实调用时刻记账，本地日上限不是套餐余额，失败调用保留。

模型行情观察行上限200，足迹原生输入上限240根5m栏，不能把两者当成同一采集范围。合格、完整覆盖且不超过模型上限的所选K线保留全部原索引、数值、时钟和单位；历史、条件及部分材料仍明确摘录，封存原件完整不等于模型已读全。24小时5分钟窗有288栏，同窗追加请求不能保证省略中段可读；用户可选更窄范围另建专题，岗位不能偷偷改任务范围。任意分段统计、连续盘口与自动因果认证不在已接工具中，下一核查不等于已完成或下轮必然可取。

手动/计划共用服务。设置间隔/每日时间、时区、窗口和预算，初始 OFF。站内切页与多标签维持租约，最后一页关闭或冻结失联后停止；恢复不补离线槽，忙时跳过，不无限排队。Vite 桥接 8 小时硬停止，启动器可更短；每轮观察不超过 30 秒。
