# P11｜九项条件分支：有触发则处理，无触发则保留证据

本文件不是默认第十二个“全部必须实现”的阶段，也不是积压清单清零目标。先读[唯一总任务](../../EXECUTION_MASTER.md)。每个分支在标注的检查点判断，可在主线中途触发，不用等四页全部完成。最终P10必须给每个分支一个明确状态。

## 1. 启用判定

“有技术触发＋必要依赖已满足＋动作在当前授权范围内”时，继续该分支的本地实现，无需为常规步骤反复问用户；涉及费用、新账号、新依赖安装、真实外部数据、常驻服务、生产读写或发布时，再核对应权限。不符合时保留`deferred`/`blocked_permission`/`blocked_evidence`，不能把unknown当allowed。

触发不意味着必须迁移或扩大架构。先选择能够解决该问题的最小方案并记录替代；如果本地安全子范围可以完成，应完成它，把真实运行验证单列待办。主线中正在使用的正确性要求不能丢到可选分支逃避。
