## 4. 本阶段执行链

1. 复用现有provider设置、REST/流式和错误适配；封存model/tool/price/prompt版本，不默认切模型或引入SDK。

2. 建立逻辑步骤与attempt身份、根预算预留、超时/取消和结果未知状态；预算缺失禁用模型而非禁用模板；费用上界未知不声称硬封顶。

3. 以卷12的P-C为综合基线，P-D仅在论证需要时审查，P-A/P-B按材料抽取/明确缺口触发；不转正五员工全部必跑。

4. 模型只生成候选，数值引用、单位、时间、能力状态和权限由程序检验；关键失败拒绝发布或回模板，不无限重试。

5. 用模拟provider完成正常、缺失、冲突、过期、假引用、取消和未知计费结果回归。真实调用需在权限记录明确允许，并使用同bundle与模板对照。
