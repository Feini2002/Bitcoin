## 4. 本阶段执行链

1. 移除abs<=1猜比例单位，资金费区分预测/最后报告/已结算和实际间隔；缺规则不默认8h，跨零变化按方法用bp或差值。

2. OI按完整产品/规格/来源分段，数量和估值分别展示；仅在V=P×Q的定义成立时使用估值分解，不把ΔOI叫净流入。

3. 账户、top账户、top持仓、taker分别命名；缺端点或缺一侧不能拿相似比值填充。

4. 将method版本与输入身份传给snapshot、压力模块和模板；条件尚未满足只输出限制，不恢复固定方向/置信度。

5. 宏观C28、期权C30依其触发条件独立登记；新增盘口或其他M方法不因资料里有公式就自动实现。

## 5. 阶段验收与跨页关系

1. 0.5/1/1.01在同一显式单位下连续；空annualized仍null；短历史不冒充24h。

2. 同family但不同产品不合并；账户数量比例不当仓位金额。

3. 页面与快照数值、单位、方法版本一致；旧记录只能按证据标记来源。

相关原场景：CHECK-001、CHECK-028、CHECK-029、CHECK-030、CHECK-031、CHECK-032、CHECK-033、CHECK-034、CHECK-035、CHECK-036、CHECK-042。P00是测试路由/基线，P10是全范围汇总；两者列全场景不表示开工前须完成全系统测试。

## 6. 阻塞与回退

保留原生观察，关闭无法成立的变化/年化/比较，不用猜单位或其他交易所值修饰显示。

不得把“安全降级可用”写成原功能已实现；不得把缺生产权限写成代码不可继续开发。代码路径确实依赖当前缺失材料时暂停该依赖链，记录可继续的独立任务。
