# 17｜验收与实验：证明数据、方法和研究价值，而非证明文件很多

## 1. 三层不同证明

第一层是实现正确性：给定输入是否遵守单位、窗口、来源、公式、状态和权限。第二层是研究合理性：结果是否受证据支持，是否存在前视、样本偏差、错误合并或不恰当因果解释。第三层是用户价值：能否更快找到重要变化、核数字、识别反证、恢复研究现场。

合成场景主要证明第一层，真实历史和前瞻对照才能触及后两层。GitHub里已有测试入口和值得保留的回归，但本轮没有运行它们，也没有把旧PASS标记当独立用例数。[C30｜package.json（读取范围见登记）](https://github.com/Feini2002/Bitcoin/blob/a6ef6c8974dcdaace32acf25c3a231ecd279ef37/package.json#L1)

## 2. 对照组

| 组 | 输入与方法 | 能识别什么 |
|---|---|---|
| B0 | 当前固定提交，原有方法和文案 | 当前实际行为；不能当已经正确的真值 |
| B1 | 同一材料，少量确认方法＋确定性模板 | 不用模型已经能达到的效果 |
| B2 | 新规范数据或新增来源，仍用同一模板 | 增量来自资料与方法，非模型措辞 |
| B3 | 与B2完全相同bundle，单次模型综合 | 解释增量与额外错误/费用 |
| B4 | 有明确缺口才调用取证/审核 | 额外研究是否找到独立信息 |
| B5 | 少量独立子任务并行、同来源与总预算 | 多代理是否优于同预算单流程 |

模板不能故意做差来衬托模型；B4获得新材料后，还应将材料交给模板再比较。所有参数和可访问来源在看测试结果前固定。过去知名事件模型可能从训练记忆知道未来结局，历史工具cutoff不能消除这种泄漏，因此历史测试不直接证明实时预测有效。

## 3. 必须检查的数值不变量

OHLC关系、非负量、量单位、taker不超过总量、窗口身份、kline累计更新替换而非反复相加、POC并列确定性、时间格/价格格守恒、未知方向分离、累计清算语义、真实锚点跨度、基差单位与费率间隔、quote/base VWAP零分母、历史vintage及来源切换。

价格格可嵌套时重采样结合性是有效测试，旧round中心格不可结合必须保留限制，不应为“测试全绿”修改expected否认数学事实。布林总体标准差与样本标准差是方法选择，不能混用同一expected。

报告数字校验同时比较值、单位、窗口、source与方法。数值碰巧相同但源是现货而报告称永续仍失败；引用URL可打开但不是对应主张也失败。

## 4. 故障注入与资源

使用隔离合成输入模拟慢REST晚于WS、重复事件、旧lease、超时但供应商结果未知、缓存返回旧schema、D1写入失败、对象写成功但manifest失败、收到空正文、数据源403/429、当前bar未完成、partial options、日历日期不确定、跨页切换和取消。

每种故障应有可观察结果：状态、未发布产物、正确保留的费用、释放的reader/timer、未推进的游标、明确缺失或有资格的部分输出。不得为了做测试去删除生产对象或大量触发实际限流。

## 5. 五项最低成本实验

### EX1 四页方法一致性

输入一组小型同源OHLCV/成交桶/衍生品/强平样本；让实际页面计算、纯方法、快照和报告输入分别输出。核对物理市场、窗口与所有数值。成功要求同方法一致、不同方法明确标不同；失败按输入/公式/显示分层定位，不让模型解释。

### EX2 主图与足迹前缀稳定性

按时间逐条增加样本，保存每一步已确认价位与SFP。后来数据可以形成新的回看评价，但不得改当时前瞻记录。加入未收盘末根与历史修订，确认两种变化分开。无原始历史时只测合成和已有覆盖，不补造交易。

### EX3 收集增量与降噪

预先选定一个有限事件面板与时间范围，比较现有事实池和一个新增获准来源。统计唯一原始事件、重要更正、延迟、错误合并、遗漏与人工核对时间。样本不能只挑热点大行情；“新增更多文章”不算成功。

### EX4 模型与模板

同bundle提供正常、缺失、冲突、过期、假引用、未启用能力和恶意外文命令。程序核数字/引用/时间/权限，人工盲评解释价值和遗漏。预算未批准则只运行模板与结构测试，模型效果保持未验证，不借此填准确率。

### EX5 部署与查询必要性

代表性现有查询分别测冷热缓存、典型/波动高峰、来源慢与重启恢复。先优化索引/范围/重复刷新，只有仍不满足用户目标才试独立批处理或数据库。结果正确、可恢复且有净维护收益才采用，不拿启动成功或厂商benchmark做决定。

## 6. 评价指标及分母

| 指标 | 采集/分母 | 防止误读 |
|---|---|---|
| 关键数值错误 | 人工/程序认可的关键数值主张中错值/单位/窗口/来源数 | 不用大量格式成功稀释一个重要错误 |
| 引用支持 | 应支持的主张中有匹配证据者；已有引用中真正支持者另列 | 覆盖与支持不同，URL存在不够 |
| 无依据解释 | 标成事实或确定结论但只能是假设的比例 | 语言自信不是校准 |
| 重要遗漏 | 预定义面板内应捕获事件/反证未出现数 | 没有全网全集不报全网召回 |
| 重复/无关 | 展示和模型输入中无新信息/无任务关联的内容 | 全删可降低重复但提高遗漏，必须联合评价 |
| 状态误用 | stale/missing/unknown被当0、当前有效或无变化 | 合法零/真实50不能误删 |
| 预警负担 | 独立episode、重复、冷却、用户有效反馈 | 点击率和惊悚程度不是价值 |
| 用户任务时间 | 等价样本的定位、核对、恢复时长与错误 | 学习效应与样本熟悉度要记录 |
| 成本 | 一份合格结果所耗总请求/模型/存储/人工 | 不只比较单token单价 |
| 维护负担 | 来源/依赖变更、事故、手工核数与修复时间 | 无观测不填精确节省工时 |

## 7. 预测实验边界

概率只针对可客观结算的问题：来源、价格类型、窗口、阈值、截止与数据中断政策固定。Brier反映整体概率损失，不只校准；同时给基率、样本量、结算率、可靠性和不确定性。不同预测期限分组，重叠24h标签不能当独立每小时试验。

事件研究先固定事件集、比较窗口、基准和主要假设。需要手续费/滑点的是可交易收益模拟，不是每个描述统计；不要因想专业而默认加账户执行。样本外失效或新增模型无增量时，退回描述方法，记录停止原因。

## 8. 发布门槛

错市场、关键数值错误、未来信息、未知方向错分、未获准外发、旧报告被无声改写、预算绕过和伪校准概率属于阻断项。风格、次要重复、个别布局可以单列，不以全愿景完美阻塞第一个有效切片。

“零错误”只指已执行的有限测试集，不是生产错误概率为零。报告必须列样本数量、覆盖、未运行项和known limitations。无法验证历史完整或模型效果时保持未知，不以文档厚度补足证据。
