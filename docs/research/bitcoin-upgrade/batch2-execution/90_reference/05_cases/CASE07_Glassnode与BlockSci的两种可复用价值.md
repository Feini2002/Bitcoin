# CASE07｜Glassnode与BlockSci的两种可复用价值

资料核验：2026-09-16。这里分析已公开的产品/方法，不声称实际使用过产品，也不复制其商业实现。


## 来源事实
Glassnode PiT说明估计链上指标历史会受标签/计算修订影响；BlockSci维护者明确停止主动支持。一个仍有商业维护的方法文档和一个停止维护的研究工具，都可能有参考价值，但复用方式不同。

## 能吸收什么
从PiT学习数据版本与计算时间，从BlockSci学习原始链到分析型结构的建模问题，从Bitcoin Core取得可独立核对的链事实。不要将三者合成一个“免费交易所资金流服务”。

## 不利条件
标签算法不可见时不能完全复算；停止维护的运行栈可能需大量环境修复；节点只有原始交易而没有经济身份。正确迁移是分层承认这些限制。

## 最小研究
选一个公开可复算链统计和一个标签估计指标，比较方法、历史版本和解释范围。前者能复算不代表后者也可复算；标签改变导致历史变化不一定是软件错误，但必须被记录。

## 当前采用结论
先增加真实问题需要的低频语境。没有实体标签来源时禁止模型猜“鲸鱼/矿工在卖”。不因BlockSci曾经知名就直接部署，也不因其停止支持就删除所有方法阅读价值。
