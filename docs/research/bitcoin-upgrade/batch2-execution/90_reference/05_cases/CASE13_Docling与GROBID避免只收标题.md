# CASE13｜Docling与GROBID避免只收标题

资料核验：2026-09-16。这里分析已公开的产品/方法，不声称实际使用过产品，也不复制其商业实现。


## 来源事实
Docling处理多格式和文档结构，GROBID偏学术结构，Unstructured提供元素化处理。此案例基于文档，不宣称实际转换过用户或第三方PDF。

## 可吸收机制
正文、表格、脚注、段落与参考文献保持身份，再生成可引用的结构化材料。对论文，重点是方法和限制；对披露，重点是数值、单位、日期与表头关系。

## 反例
把“金额（百万美元）”表头丢掉后，数字仍是合法JSON，却已失去金融含义。把一段研究假设抽成肯定结论，比漏掉一段营销文字更严重。扫描负号识别错误不能靠语言流畅掩盖。

## 小实验
用获准人工标注样本比较不同工具，分开评估数字准确、单位、阅读顺序和证据定位。原生结构化格式优先，OCR仅在必要时使用并核查关键字段。

## 当前适用
把研究论文、发行人报告和方法文档作为独立资料库支线，不要求实时日报每次解析大量PDF。来源权利不允许全文保存时，保留许可范围内元数据和不可完全重放标记。
