# CASE08｜Anthropic研究案例与TradingAgents的可迁移部分

资料核验：2026-09-16。这里分析已公开的产品/方法，不声称实际使用过产品，也不复制其商业实现。


## 来源事实
厂商工程案例讨论并行研究的任务分解与成本，TradingAgents的变更记录包含历史输入等修正。它们不是在相同BTC数据/预算下做过的直接对照。

## 正向应用
多个独立问题可以并行：核合约规格、查官方披露、查相反主张。每个子任务提供原始证据及不足，主分析在固定材料包上综合。价值来自独立工作，不来自角色名字。

## 反例
让五个角色读同一错误摘要，会得到相关的错误意见；再由一个首席投票并不产生独立验证。多轮讨论还可能忘记最初窗口或重复搜索同根源。

## 公平试验
同任务、同总预算、同可访问来源、同截止点比较模板/单模型/条件核查/并行图。统计重要遗漏、无依据主张、来源独立、延迟和取消后费用，而不是比较文本长度。

## 对原方案的纠偏
不能把“多代理不是默认”升级为“多代理从不值得”。本库保留完整框架比较；当前实现先交付小流程，独立研究子问题出现且增量成立时再拆。
