# 当前切片任务｜按实际启用能力，而不是按完整愿景排队

F编号界定本次最小范围，WP保留完整细节与partial映射。不是删除必要依赖；使用中的身份、用途、数值语义、时间、费用与失败边界仍须完成。

五种profile：market_template为已有市场数据的确定性简报；collection_pilot为独立来源/版本试点；integrated_template连接前两者；model_brief仅在已有市场模板上加模型，不强制新来源；integrated_model在已接入有限事件的模板上加模型。后两者都不是默认启用。

F-08/09的测试设计可提前并行，依赖表示验收所需产物，并不要求所有编码串行。共享文件一个集成owner；完成只指本scope。交付可保持待部署，不自动操作生产。
