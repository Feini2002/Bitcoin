# RES17｜报告质量评价与可观测性

研究日期：2026-09-16。本卷是独立基础研究，不要求匹配当前仓库；“建议/迁移启示”是本研究的推论，不是项目官方承诺。未运行候选代码。


## 1. 五类错误分开评价

数值错误、引用不支持、时间错位、关键遗漏和无关重复不是同一指标。一个总分可能让流畅文风掩盖严重伪造数字。建议关键错误硬门与一般质量分层：关键数值/来源/权限不通过就拒绝发布，语言质量和阅读负担用于比较候选。

ALCE提供引用评价方向；promptfoo可以组织断言；Langfuse记录trace与版本。它们分别是方法、测试和观测，不替系统提供金融事实标签。[EXT136｜ALCE引用生成评估论文](https://aclanthology.org/2023.emnlp-main.398/) [EXT082｜promptfoo 官方仓库](https://github.com/promptfoo/promptfoo) [EXT080｜Langfuse 官方仓库](https://github.com/langfuse/langfuse)

## 2. 标注与分母

数字正确性以明确数字主张为分母，引用支持度以需要证据的主张为分母，重复率以去除同源后剩余信息量或事件条目为单位，重要遗漏以预先标注的关键事件集为分母。不能将所有句子平均，靠大量无关正确句稀释一条严重错误。

样本涵盖正常、缺失、陈旧、矛盾、来源回退、统计单位变动、相似辟谣和恶意输入。既要有合成边界，也要有获准真实材料；合成测试通过不证明真实召回和用户价值。训练/调prompt样本与最终评价按事件和时间隔离。

## 3. 观测链最小字段

根任务、步骤、输入包、prompt/模型/工具版本、开始结束、结果身份、费用估算与实际用量、错误和降级原因。数据权利不允许留全文时只保存获准身份与摘要，不以排障名义外发全部材料。

trace要能回答一次报告为什么使用旧数据、哪些工具重复、何处超时，以及最后报告是否已经发布。记录成本不是限制成本；根预算需要预留、结算、失败释放和并发保护，子任务不能各拿一份完整总预算。

## 4. 基线与盲评

同一材料比较旧版、确定性模板和新版，随机隐藏版本标签供人工判断：是否更易核对、是否指出重要反证、是否减少不必要文字。模型裁判只能补充，不要让生成器和裁判共享同一未验证结论后互相认可。

DSPy等优化框架只有在评价有效时才有价值，否则只是把偏差优化得更稳定。模型版本升级后用同一集回归，再用新的时间后样本检验，不能永久围绕一份测试集调优。[EXT078｜DSPy 官方仓库](https://github.com/stanfordnlp/dspy)

## 5. 发布与历史

流式预览不等于已验证最终报告。预览可覆盖更新，final应有独立版本或明确不可变身份；语法修复不得自行补金融事实。取消、超时和预算耗尽产生不同状态，历史页面不把partial显示成正常结论。

用用户研究任务而非阅读时长单独评估效率。短报告可能遗漏关键内容，长报告可能让人放弃；目标是完成核对/定位/复盘更少错误。没有实际测量时，只列评价设计，不填提升百分比。
