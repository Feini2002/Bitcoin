# 本轮研究过程与检索覆盖

日期：2026-09-16。这是主题化工作记录，不声称是每一次工具调用的逐字日志；可复用的中英文查询模板在06_collection_design，不冒称所有模板均逐字执行过。

## 实际顺序

1. 阅读原执行方案的研究、提示词及任务材料；检查原包结构并解析tasks.json，定位最小切片的传递依赖。
2. 按持续订阅、正文提取、中文情报平台补查RSSHub、Miniflux、FreshRSS、changedetection、TrendRadar、zenfeed、Readability、Trafilatura、Scrapy、Crawl4AI和Firecrawl。
3. 按新闻对象、去重、语义检索补查IPTC ninjs、W3C Annotation、Feedly三篇具体方法说明、datasketch、Sentence Transformers、FTS5、Media Cloud和Event Registry。
4. 按完整金融平台与专项方法复查OpenBB、Qlib、TradingAgents、FinRobot、FinGPT、Nautilus、HftBacktest、BlockSci等，重点找开放版本、维护声明、数据假设和不利证据。
5. 复核交易所协议、Deribit采集、历史服务、FRED/ALFRED、Fed/BLS、SEC及发行人/稳定币披露；数据方法与调用权利分别记录。
6. 按研究评价补查OFI论文、ForecastBench及评估陷阱、概率校准、arch、DoWhy、River、ruptures，不外推论文结果到BTC。
7. 按运行/工作区比较DuckDB、Polars、dlt、Dagster、Temporal、Haystack、LangGraph、LlamaIndex、Langfuse、DSPy、promptfoo、FDC3与图表组件。
8. 最后补复杂文档摄取与检索服务：Docling、GROBID、Unstructured、Qdrant；核对主库许可和模型/服务边界。
