# RES14｜预测校准观点与决策记录

研究日期：2026-09-16。本卷是独立基础研究，不要求匹配当前仓库；“建议/迁移启示”是本研究的推论，不是项目官方承诺。未运行候选代码。


## 1. 观点不必全部强制概率化

“价格上涨但OI不支持，需要下一窗口确认”是条件判断；“未来24小时某市场收盘高于X的概率为p”是可结算预测。两者需要不同记录和评价。数据完整度、来源质量、语言自信与概率不能共用confidence百分数。

ForecastBench的方法价值是以尚未结算的事件评价，相关研究也警示外部人类预测和时间信息渗入输入。不能从历史论文结果直接得出当前模型谁最强。[EXT090｜ForecastBench 论文v4](https://arxiv.org/html/2409.19839v4) [EXT091｜LLM预测评估的陷阱](https://arxiv.org/html/2506.00723v1)

## 2. 预测问题的最低规范

明确市场、价格类型、是否触及或收盘、阈值、观察起止、时区、结果来源、缺失/停牌等无效条件和结算程序。概率提交必须早于目标事件，修订保留每次概率和信息时点；不允许结果发生后改题或删掉失误。

如果同一问题一天更新多次，必须预声明评价按首次、最终有效预测还是时间加权，不能挑最好的一次。模型工具可看见预测市场价格或其他人概率时，应标记这是输入条件，不能将其复制能力误当独立预测能力。

## 3. 评分与校准

二元Brier可按平均(p-y)²计算，较小值通常更好，但混合反映校准与区分等因素；可靠性图需要足够样本并显示每桶数量。与基础频率比较技能比只报绝对分数更有意义。Log loss对极端错误敏感，使用数值裁剪时应报告规则，不让数值处理悄悄改变评价。[EXT087｜scikit-learn 概率校准](https://scikit-learn.org/stable/modules/calibration.html)

同一个市场的高度重叠窗口不是大量独立样本。按时间段、问题类型和市场状态分层，并报告区间；没有足够前瞻样本时不要给“胜率已证明”。历史模型可能记住事件，即便检索只读过去也不能自动排除训练记忆。

## 4. 决策记录的结构

建议记录原问题、原证据包、选择的解释、反证、成立/失效条件、下一观察点、用户实际动作（可空）、结果以及过程教训。判断正确但理由错误，与理由合理但结果不利应分别记录，避免把好运误当能力。

该记录不是账户交易日志，不要求余额和持仓权限。模型只能评价已保留的当时材料，不能今天重写过去理由。修订要附加，而不是覆盖。

## 5. 评价流程

先运行“只记录不排名”的前瞻样本阶段，保证题目能客观结算，再比较模板、单模型、多人或规则。错误包括无法结算、源失效、未来信息、事后改题和选择性删除，不只预测错。

当预测没有稳定增量时，系统仍可在事实核对、事件发现和上下文恢复上有价值；不要为保留一个概率模块反复改评价标准。停止预测展示、保留研究记录是合理退出方案。
