# TOOL020｜W3C Web Annotation

查询日期：2026-09-16。已核验事实仅限下列直接材料；实验未执行。

## 身份与直接证据

类型：证据定位规范。

规范以注释主体与目标、选择器表达对内容的定位和说明。它解决引用指向哪里，不负责证明该内容正确。

[EXT043｜W3C Web Annotation Data Model](https://www.w3.org/TR/annotation-model/)

## 可以吸收的具体成果

将主张指向文档某版本与允许保留的短片段、位置、前后文；记录定位策略及提取器版本。正文变化时检验定位是否仍可恢复，而不只保存一个网站主页链接。

## 不适用与负面证据

字符偏移会受清洗和翻译影响；TextQuote相同也可能出现多处。网页内容删除后，不应凭模型记忆恢复引文。

## 代码、数据与服务权利

规范与实施代码许可分别审阅；本研究仅借鉴模型。短引用、全文保存及公开展示受原内容权利约束。

## 运行与成本边界

可在现有JSON/数据库中表示，不需要图数据库。检索时按document_version解析，失败返回unresolved。

## 维护证据及其限度

规范成熟；浏览器/供应商实际支持及自选解析器维护未核。

## 竞争替代与选型条件

简单source_id＋段落ID容易实现；若需要跨系统引用和精细定位，使用规范子集有更清晰语义。

## 最低成本核验实验

对页面加入广告、改标点、更新正文、翻译四种变更测试；验证只在同一允许版本定位，不能静默跳到含义不同的新段落。

## 两轴判断

**一般适用性：**适合证据追踪与研究笔记。

**当前仓库适用性：**推荐借鉴选择器和目标版本，不强制实现全规范。
