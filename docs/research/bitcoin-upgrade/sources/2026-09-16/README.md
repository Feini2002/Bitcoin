## 本轮实质变化

统一时间/用途词汇；修复Schema根入口与覆盖反例；补齐模板和历史研究请求；区分URL首次见与正文版本首次见；允许带当前更正提示的合法私有历史审计；说明真正可保证的计费与恢复边界；提供不依赖所有市场类别的切片图。当前正文、机器材料、示例和合订本一并更新。

## 第一份交付应该是什么

用现有可用市场输入生成一份“变化—分歧—条件—未知”的可追证简报，能回到输入和正确历史页面。缺比较时建立基线，缺来源时说明覆盖不足，没有重要变化则允许短输出。修复FNG缺失和固定置信度的误导，但不把每个启发式规则一概视为非法；规则可作为明确的描述约定，不能冒充校准预测。

新来源试点解决具体盲区，可与简报并行；并非所有简报都必须等待它。模型增强只有在同证据对照显示解释增量后保留。期权、ETF、完整历史盘口、独立计算、多代理和全部原型页面不是首交共同前置。

## 操作与验证边界

本轮只处理文档、参考JSON/Schema/SQL和合成样例。没有修改真实仓库、运行第三方候选、接入账号、调用真实模型、抓取生产市场数据、迁移D1或部署。离线检查脚本由本轮编写，仅验证包内材料，不自动执行，缺依赖时退出而不安装。

用户批准一次scope可以授权范围内连续开发与本地测试，不要求把人工审批做进每次产品运行。安装、外部访问、费用、生产写入、删除和部署必须包含在明确范围中；未包含不自动获得授权。不要将文档包加入Pages发布资产。
