配套阅读：`docs/research/binance-fixed-ip-proxy-plan-2026-09-19.md`（技术方案）、`docs/research/binance-egress-block-2026-09-19.md`（问题归因）。

## 0. 结论先行

- 你要买的是：**一台境外、按月几美元、Ubuntu 系统的入门级 VPS**（虚拟小服务器）。
- 地区首选**东京**，其次新加坡、首尔、大阪。**不要选美国**。
- 配置买**最低档**即可，1 核 1GB 绰绰有余（这种转发很轻）。
- **必须选支持「按小时计费」的商家。**
- **不需要**：域名、备案、SSL 证书、币安 API Key、高配置、Windows。
- 最容易踩的坑：**买最便宜的机房机器不一定能通**，原因见 §2。所以先用小时计费试，试不通只花几分钱。

## 1. 这台机器要干什么

只有一件事：**把 Cloudflare 发来的请求原样转给币安，让币安看到的是它自己那一个固定 IP。**

它不存数据、不算指标、不碰数据库。所有业务逻辑仍在 Cloudflare Worker 里。所以它**不需要好配置**——1 核 1GB 的入门款性能远超所需。

## 2. 买之前必须懂的三个认知（重要）

### 2.1 最大的不确定性：币安可能不是按「具体 IP」，而是按「这是机房 IP」来封

这是本次复核新查到的关键信息，会直接决定这笔钱花不花得值：

- 有记录显示，从**机房/数据中心 IP** 请求币安的公开接口，会被返回 `451`（地域封锁），且直连无法绕过（来源 S16）。
- 更细的分析指出，很多封锁是按 **ASN 的使用类型**判断的（`hosting`/`datacenter` vs `isp`/`residential`），而不是看请求头；**换一个机房 IP，本质只是换了一个机房 ASN**，如果对方按类别过滤，换了照样被封（来源 S17）。
- 同一份记录也强调：**共享 IP 池里别人的行为会算到你头上，重要目标要用独享 IP**（来源 S17）。

**这意味着两种可能，购买前无法确定：**

| 情况 | 结果 | 应对 |
| --- | --- | --- |
| 币安只封了 Cloudflare 的段（或按来源特征拦 CF） | 普通机房 VPS **能通** | 最省钱，几美元/月搞定 |
| 币安按「机房 IP 类别」整体拦 | 普通机房 VPS **也不通** | 只能上住宅/ISP 代理（要花钱且与仓库规则冲突）或自备家用常开机器 |

**所以本清单的核心原则是：先花几分钱试，不要一上来买年付。** 社区里两种结果都有记录，必须以你实际试出来的为准。

### 2.2 币安对「不在白名单的 IP」和「地域封锁」返回的 403 长得一样

本仓库只用**公开行情接口、不用 API Key**（已核对：`wrangler.toml` 无币安密钥配置，代码里也没有签名逻辑），所以**不需要**做 IP 白名单——这一步省掉了。

但要记住这两种 403 外观相同（错误码 `-2015`），以后排查别混（来源 S14）。

### 2.3 这件事没有「一劳永逸」

- 有记录明确写过：某交易所「几个月来一直正常，某天突然开始 403，没有任何公告」，**已封的可能解封，没封的可能突然封**（来源 S16）。
- 所以别指望买一次管一辈子。要配合监控，哪天不通了再换机器。

## 3. 选商家：看这 7 个指标

1. **有你要的地区**：东京优先（社区案例用东京，延迟低）。确认商家官网当前有机房。
2. **支持按小时计费**：失败试错成本才能压到几分钱。这是硬指标。
3. **给你一个真正独享的固定 IPv4**：不要共享出口 IP 的低价款。
4. **流量额度够**：这类转发请求量很小，1TB/月绰绰有余；但仍要看清楚额度。
5. **付款方式你能用**：国内用户重点看是否支持支付宝。
6. **系统镜像有 Ubuntu**：选 Ubuntu 22.04 或 24.04（LTS），别选 Windows。
7. **能退/能销毁**：按小时计的机器通常随时可以删掉不再计费。

## 8. 费用与安全护栏

- **试错阶段**：按小时计费，$0.007/小时量级，试一天成本约几美分。这是本清单最重要的省钱点。
- **长期阶段**：$5~7/月量级，一年几十美元。以商家官网当期价格为准。
- **止损线**：建议给自己定个上限——比如「试 2~3 台机器、总花费不超过约 $20 还不同，就停下来重新评估」，别无限换机器。
- **安全**：反代必须带共享密钥，且限制只能访问币安；否则会变成公开匿名代理，被滥用后 IP 再被封，钱白花。

## 9. 如果试不通，退路是什么

按仓库规则与现实成本排序：

1. **换另一个地区/商家再试**（成本低，值得试 2~3 次）。
2. **换用 ISP/住宅代理**（如 Bright Data）：这是社区在机房 IP 被封后采用的方案，但要**按流量付费、成本明显更高**，且用代理绕过地域限制与仓库规则冲突，**需你单独授权**（来源 S5、S17）。
3. **自备家用常开机器**：免费，但需要家里有台机器一直开机，家庭 IP 稳定性与上行带宽都是问题。注：之前测到本机可通是因为本机在跑 FlClash 代理，**不能据此认为家里真实出口能通**，需要单独验证。
4. **接受部分数据长期滞后并显式标注过期**：零成本，代价是数据不新。

**不建议**：用其他交易所数据静默顶替币安；频繁换域名重试。

## 10. 常见疑问

- **要不要买域名？** 不要。IP 直接访问即可。
- **要不要备案？** 不要。这是境外机器，不涉及。
- **要不要币安 API Key？** 不要。仓库只用公开行情接口。
- **要不要装宝塔之类的面板？** 不要。越小越安全。
- **能不能买 Windows？** 不要，Ubuntu 更轻更省。
- **能不能用免费主机？** 免费额度通常共享 IP、随时回收，且大概率已经是高滥用段，成功率低，不建议作为第一次尝试。
- **我会不会被商家坑？** 按小时计费即可随时止损；先买最小档试通再考虑长期。

## 11. 附：Vultr 东京逐步下单（2026-09-19 核实）

以下步骤与计费细节来自 Vultr 官方文档与实测教程（来源 S18、S21）。**价格与界面以你下单当天官网为准。**

### 第 1 步：注册账号

1. 打开 Vultr 官网，用邮箱 + 密码注册（密码要求：至少 10 位，含大小写字母和数字）。
2. 去邮箱点激活链接。
3. 填写账单信息。

### 第 2 步：绑定支付方式并充值

- Vultr 支持**支付宝**、银联、PayPal、信用卡、加密货币等（来源 S18）。
- 建议**先充小额**（例如 $10），够试好几台机器，避免绑卡后被自动续费。

### 第 3 步：部署服务器

1. 左侧菜单进 **Products**，点右上角 **+**（Deploy）。
2. 服务器类型选 **Cloud Compute**。
3. 地区（Location）选 **Tokyo / 东京**。
4. 镜像（Image）选 **Ubuntu**，版本挑 LTS（22.04 或 24.04）。**不要**选 Marketplace 里的预装应用。
5. 机型（Plan）选**最低档**，1 vCPU / 1GB 那种（对应约 $5/月档）。
6. Additional Features 里选一个 **SSH Key**（推荐），或让系统给 root 密码。
7. 点 **Deploy Now**，等状态从 `Installing` 变成 `Running`。

### 第 4 步（最关键，关系到扣钱）

**用完试不通要「Destroy」，不是「Stop」。**

Vultr 官方明确：**服务器停止（Stop）后依然计费**，因为它仍占用 CPU、内存、硬盘和 IP；只有 **Destroy** 才会释放资源并停止计费（来源 S22）。最小计费单位是 1 小时。

所以：

- 试完不通 → 立刻 **Destroy Server**。
- 试通了要长期用 → 保持 Running 即可，约 $5/月。
- **不要**点 Stop 就走人，那会一直计费。

### 第 5 步：省钱三条

1. **不要开启自动备份**：会让基础费用**增加 20%**（来源 S21）。这台机器没数据可丢。
2. **不要年付**，按小时/按月即可。普通款每月计费上限 672 小时（约 28 天），不会因月份天数多扣（来源 S21）。
3. **试不通立刻销毁**，成本约几美分。

### 第 6 步：买完给我这四样

- 服务器 **IP 地址**
- **root 密码**（或你选的 SSH 私钥）
- 你选的**地区**（东京）
- Vultr **控制台登录**（仅在需要销毁/重建时用，可以稍后再给）

拿到后我会先在这台机器上单独验证能否访问币安——**通不过就立刻叫你销毁，不浪费后续功夫**。

### 第 7 步：注意流量

- 月流量额度 1TB 级，这类转发请求量极小，正常用不完。
- 超出按约 $0.01/GB 计费（来源 S21）。若发现流量异常高，多半是反代被人白嫖，说明鉴权没做好。
