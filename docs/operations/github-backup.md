# GitHub 源码备份

仓库默认远程为 origin，项目默认分支为 main。操作前以当前 Git 状态和远程配置核实目标。

## 备份

- 仅在用户明确要求时 commit、push 或创建 PR；普通本地治理不自动推送。
- 提交前检查已有改动与暂存范围，保留其他任务的修改。
- 生成产物 dist/、.artifacts/、本地环境文件、日志和依赖缓存由忽略规则排除。
- 按 AGENTS.md 运行相应验证；发布与否遵从当前授权，不能为了备份擅自恢复服务或修改 D1。
- 提交说明描述实际变更和验证结果。遇到远程分歧先检查事实，不自动 reset、强推或覆盖未提交内容。

## 恢复

- 从已确认的提交建立独立检出或工作树进行检查，验证通过后再决定如何合并回来。
- Git 保存源码与迁移历史，不代表已经备份 D1 内容、Cloudflare 账号配置或凭据。
- 本仓库的数据库迁移记录保留；删除旧执行路径不自动删除远程历史数据。

当前执行约束以根目录 AGENTS.md 为准。
